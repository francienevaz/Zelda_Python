# Zora - Jogo de Aventura em Python (versão DEMO)
### Descrição
Zora é um jogo de aventura inspirado em clássicos como Zelda, desenvolvido em Python utilizando a biblioteca Pygame. Explore um mundo cheio de desafios, colete itens, derrote inimigos e descubra segredos escondidos.

### Como Jogar
Controles Básicos
- Movimento: Teclas WASD ou Setas Direcionais

- Ataque: Barra de Espaço

- Trocar Arma: Tecla Q

- Menu: ESC

### Mecânicas do Jogo
Sistema de Vida: Representado por corações no canto superior esquerdo

Troca de Armas: Colete diferentes armas para variar seu estilo de combate

Sistema de Experiência: Derrote inimigos para ganhar EXP e fortalecer seu personagem

### Requisitos do Sistema
- Python 3.8+

- Pygame 2.0+

Instalação
Clone o repositório:

``` bash
git clone https://github.com/seu-usuario/zora-python.git
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o jogo:

```bash
python main.py
```
